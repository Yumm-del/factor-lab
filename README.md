**让 AI 在安全约束内挖掘 A 股因子：一句话想法 → 受限表达式 → 量化研究标准体检 → 策略回测**

## 这是什么

AI 挖因子有两条路线：让模型批量生成上万个因子再筛（快，但黑盒难追溯），或让 AI 把研究想法翻译成**受限表达式**（一个因子、全流程验证、每一步可查）。

因子实验室走第二条：LLM 的输出被限制在 **38 个白名单算子**构成的表达式树上——**AI 有创造空间，但没有越权空间**。因子进入工作台后，走与人工因子完全相同的量化研究标准体检（IC、分层回测、换手率、IC 衰减、综合评分），不达标时触发**反思迭代闭环**自动改进，最终可一键构建 Top-N 组合并与沪深300 指数对比。

```
自然语言想法              受限 DSL 表达式               量化研究标准体检              AI 解读            策略
"放量后延续上涨" ──LLM──▶ rank(量比5/20 × 动量20) ──自动──▶ IC / RankIC   ──LLM──▶ 大白话报告   ──▶ Top-30 组合
                           ↓ 白名单算子 + 深度限制           分层回测        + 改进建议        扣成本、对比
                           （不能执行任意代码）               换手率                             沪深300 指数
                                                              IC 衰减曲线
                                                              综合评分（0-100）
```

## 核心特性

- **受限智能体 DSL**：38 个白名单算子（14 时序 + 2 二元时序 + 3 截面 + 6 一元 + 12 二元 + 1 条件），表达式树深度 ≤ 8、节点 ≤ 64，非法输入在**解析层**被拦截（中文报错）——结构安全，不是事后审查；
- **可审计的安全证据**：69 条离线固定用例覆盖合法公式、代码注入、越权算子、畸形 JSON、非法参数、隐藏字段与资源耗尽，当前合法公式通过率和危险输入拦截率均为 **100%**；逐例结果见 [`docs/evidence/security_benchmark.md`](docs/evidence/security_benchmark.md)；
- **经典因子库 91 个**：10 个教科书因子 + 81 个 WorldQuant 101 公式移植（与公开参考实现逐日相关交叉验证，27/27 双向验证全 >0.99），全部与 AI 因子同一体检管线；
- **量化研究标准验证引擎**：每日截面 IC/RankIC（当日因子值 vs T+1 收益，无未来函数）、5 层分层回测、组合换手率、IC 衰减曲线、综合评分（tanh 压缩防过拟合刷分）；
- **反思迭代闭环**：体检评分 < 50 时，失败诊断回喂 LLM，LLM 基于体检证据修改表达式后重新体检，最多迭代 2 轮，迭代轨迹完整保留——「AI 挖因子」不是单轮生成，而是自主迭代；
- **因子池查重（AlphaPool 式）**：每轮生成先与因子池（内置 91 因子 + 会话已挖因子）逐日截面相关，中位 |corr| > 0.99 判重复——重复时把「与已有因子 X 高度相似，请改变核心逻辑」作为反思反馈优先回喂，杜绝反复生成等价因子；设计思想借鉴 AlphaForge（AAAI 2025）AlphaPool（自行实现，不引用其代码）；
- **双股票池 + 中性化**：沪深300（300 只）与全 A 股（5300+ 只）双池，支持行业/市值中性化（每日截面回归剥离混淆）；
- **策略构建与全因子 PK**：Top-30 周频、双边 20bps 成本、真实沪深300 指数基准，全部因子同规则同屏对比；
- **手动表达式编辑**：支持输入人类可读公式（`rank(ts_mean(close,5)/ts_mean(volume,20))`）或 JSON 表达式树，不依赖 API 即可完成体检；
- **全链路可解释**：表达式树可视化、因子逻辑自述、体检报告、因子生命周期图（60 日滚动 IC，失效如实画出）。

## 架构

```

      │
      ▼
dsdl（受限 DSL：解析器 + 白名单校验 + 向量化求值 + 公式<->树互转）
      │
      ▼
validation（验证引擎：IC/分层/换手/衰减/评分/生命周期）
      │
      ▼

      ▲
      │
llm_factor（LLM 编排：生成 → 反思迭代 → 解读报告，DeepSeek API，接口可替换）
      │
      ▼
factor_pool（因子池查重：内置 91 因子 + 会话已挖因子，逐日截面相关 >0.99 判重复，
             重复时作为反思反馈强制换逻辑）
      │
      ▼
app.py（Streamlit 单页工作台：AI 因子工场/经典因子库/因子对比/策略构建）
```

## DSL 算子（白名单 38 个 + 10 个数据字段）

| 类别 | 算子 |
|---|---|
| 时序 (14) | `ts_returns` / `ts_mean` / `ts_std` / `ts_zscore` / `ts_rank` / `ts_max` / `ts_min` / `delay` / `delta` / `ts_sum` / `ts_product` / `ts_argmax` / `ts_argmin` / `decay_linear` |
| 二元时序 (2) | `ts_corr` / `ts_cov` |
| 截面 (3) | `rank` / `normalize` / `scale` |
| 一元 (6) | `neg` / `abs` / `log` / `ln` / `sign` / `signed_power` |
| 二元 (12) | `add` / `sub` / `mul` / `div` / `pow` / `min` / `max` / `gt` / `lt` / `eq` / `and` / `or` |
| 条件 (1) | `cond`（对应 WorldQuant `?:`） |
| 数据字段 (10) | `open` / `close` / `high` / `low` / `volume` / `amount` / `vwap` / `turn` / `pe` / `pb` |

> 窗口参数范围以引擎为准（如 `ts_mean` 2~260、`ts_rank` 2~120），LLM 与手动输入超出范围会被解析层拦截并中文报错。

## 安全设计（为什么这是「结构安全」而不是「约定安全」）

- LLM 输出先过 JSON Schema 校验，但真正的安全保证在**解析层**：`dsdl.parse_factor` 递归逐节点检查（算子白名单、param 区间、深度 ≤8、节点 ≤64），非法输入直接拒绝——即使 LLM 被诱导输出恶意结构也无法通过；
- 因子求值是**纯向量化数据操作**：无任意代码执行路径、无文件系统访问、无网络请求；
- 安全边界不是只靠说明文档：`python scripts/security_benchmark.py` 可离线复跑 69 条固定用例，机器可读结果保存在 `docs/evidence/security_benchmark.json`；
- 对比「LLM 写 Python 代码 + 回测防火墙」路线（如 RD-Agent/Qlib 类），本项目牺牲表达自由度，换取结构保证与全流程可解释。

## 已知问题与边界（诚实清单）

- **滑点/冲击成本/资金容量未建模**：回测只扣固定双边成本，大资金实盘会劣化；
- **FDR 校正已做、双池结果截然不同**：91 个内置因子沪深300 全样本名义显著 6 个、校正后 0 个（最佳 q=0.0975）；同批因子全 A 池（5320 只）名义显著 30 个、校正后 27 个（t 4.7~6.3）——差异是统计功效（截面大小）而非矛盾，FDR 过关只回答「信号不是运气」、不回答「可交易」（见 `scripts/verify_robust.py`、`scripts/verify_ashare.py`）；
- **全 A 池未剔除上市初期（<60 交易日）样本**：新股波动极端会拉高截面噪声，v1.1 数据层改进；
- **数据源依赖**：baostock 为免费公共服务器，深夜存在不可用窗口，下载脚本已实现断点续传与重连；
- **反思迭代的实测**：机制真实（淘汰档因子获得第二次机会），但迭代后分数未必超过首轮——迭代价值在于「不粉饰失败的探索过程」；
- **候选因子并未因此获得接纳**：原始 AI「放量延续」已在 BigQuant 独立复核中淘汰；经典低波动也在留出期转弱。项目的输出可以是“拒绝”与“风险提示”，而非只输出收益数字；
- **因子池查重为会话级记忆**：不跨会话持久化（重启后池重置），阈值固定 0.99——持久化与分层阈值已列入路线图 v1.0；
- **v0.9 未经真实用户反馈**：请通过 Issue 报告问题与建议。

## 路线图

- v1.0（2026-09~10，进行中）：walk-forward 时间分割稳健性 + FDR 多重检验校正（**已完成并接入工作台**，`factor_lab/robust.py`）、全 A 池验证闭环、真实用户反馈收敛；
