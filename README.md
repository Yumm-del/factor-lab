## 这是什么

AI 挖因子有两条路线：让模型批量生成上万个因子再筛（快，但黑盒难追溯），或让 AI 把研究想法翻译成**受限表达式**（一个因子、全流程验证、每一步可查）。

因子实验室走第二条：LLM 的输出被限制在 **18 个白名单算子**构成的表达式树上——**AI 有创造空间，但没有越权空间**。因子进入工作台后，走与人工因子完全相同的量化研究标准体检（IC、分层回测、换手率、IC 衰减、综合评分），不达标时触发**反思迭代闭环**自动改进，最终可一键构建 Top-N 组合并与沪深300 指数对比。

```
自然语言想法              受限 DSL 表达式               量化研究标准体检              AI 解读            策略
"放量后延续上涨" ──LLM──▶ rank(量比5/20 × 动量20) ──自动──▶ IC / RankIC   ──LLM──▶ 大白话报告   ──▶ Top-30 组合
                           ↓ 白名单算子 + 深度限制           分层回测        + 改进建议        扣成本、对比
                           （不能执行任意代码）               换手率                             沪深300 指数
                                                              IC 衰减曲线
                                                              综合评分（0-100）
```

## 核心特性

- **受限智能体 DSL**：18 个白名单算子（8 时序 + 2 截面 + 4 二元 + 4 一元），表达式树深度 ≤ 8、节点 ≤ 64，非法输入在**解析层**被拦截（中文报错）——结构安全，不是事后审查；
- **量化研究标准验证引擎**：每日截面 IC/RankIC（当日因子值 vs T+1 收益，无未来函数）、5 层分层回测、组合换手率、IC 衰减曲线、综合评分（tanh 压缩防过拟合刷分）；
- **反思迭代闭环**：体检评分 < 50 时，失败诊断回喂 LLM，LLM 基于体检证据修改表达式后重新体检，最多迭代 2 轮，迭代轨迹完整保留——「AI 挖因子」不是单轮生成，而是自主迭代；
- **双股票池 + 中性化**：沪深300（300 只）与全 A 股（5300+ 只）双池，支持行业/市值中性化（每日截面回归剥离混淆）；
- **策略构建与全因子 PK**：Top-30 周频、双边 20bps 成本、真实沪深300 指数基准，全部因子同规则同屏对比；
- **手动表达式编辑**：支持输入人类可读公式（`rank(ts_mean(close,5)/ts_mean(volume,20))`）或 JSON 表达式树，不依赖 API 即可完成体检；
- **全链路可解释**：表达式树可视化、因子逻辑自述、体检报告、因子生命周期图（60 日滚动 IC，失效如实画出）。

## 架构

```
data_pipeline（baostock 双池下载/断点续传/unstack 宽面板）
      │
      ▼
dsdl（受限 DSL：解析器 + 白名单校验 + 向量化求值 + 公式<->树互转）
      │
      ▼
validation（验证引擎：IC/分层/换手/衰减/评分/生命周期）
      │
      ▼
strategy（策略构建：Top-N 组合 + 成本 + 指数基准 + PK）
      ▲
      │
llm_factor（LLM 编排：生成 → 反思迭代 → 解读报告，DeepSeek API，接口可替换）
      │
      ▼
app.py（Streamlit 单页工作台：AI 因子工场/经典因子库/因子对比/策略构建）
```

## DSL 算子（白名单 18 个）

| 类别 | 算子 |
|---|---|
| 时序 (8) | `ts_returns` / `ts_mean` / `ts_std` / `ts_zscore` / `ts_rank` / `ts_max` / `ts_min` / `delay` |
| 截面 (2) | `rank` / `normalize` |
| 二元 (4) | `add` / `sub` / `mul` / `div` |
| 一元 (4) | `neg` / `abs` / `log` / `signed_power` |

## 安全设计（为什么这是「结构安全」而不是「约定安全」）

- LLM 输出先过 JSON Schema 校验，但真正的安全保证在**解析层**：`dsdl.parse_factor` 递归逐节点检查（算子白名单、param 区间、深度 ≤8、节点 ≤64），非法输入直接拒绝——即使 LLM 被诱导输出恶意结构也无法通过；
- 因子求值是**纯向量化数据操作**：无任意代码执行路径、无文件系统访问、无网络请求；
- 对比「LLM 写 Python 代码 + 回测防火墙」路线（如 RD-Agent/Qlib 类），本项目牺牲表达自由度，换取结构保证与全流程可解释。

## 已知问题与边界（诚实清单）

- **滑点/冲击成本/资金容量未建模**：回测只扣固定双边成本，大资金实盘会劣化；
- **多重检验校正未做**：目前靠「人给想法、AI 翻译」限制假设空间 + tanh 评分压缩防过拟合，正式校正（FDR/Bonferroni）是后续迭代；
- **全 A 池未剔除上市初期（<60 交易日）样本**：新股波动极端会拉高截面噪声，v1.1 数据层改进；
- **数据源依赖**：baostock 为免费公共服务器，深夜存在不可用窗口，下载脚本已实现断点续传与重连；
- **反思迭代的实测**：机制真实（淘汰档因子获得第二次机会），但迭代后分数未必超过首轮——迭代价值在于「不粉饰失败的探索过程」；
- **v0.9 未经真实用户反馈**：请通过 Issue 报告问题与建议。
