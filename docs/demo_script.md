# 3 分钟演示视频脚本 v2（2026-09-07 冻结口径）

> 目标：让评委记住一句话——**我们不把 AI 当收益预言机，而是让它在受限、可验证、可否决的流程里做研究。**
> 本版与方案书 9/7 口径一致：38 算子 / 69 用例 / 0/5 淘汰 / Alpha#25 独立复现。总台词约 700 字 ≈ 2:55。
> 取代 v1（缺 Alpha#25 存活证据）与 docs/voiceover.md（18 算子、+14.4% 当卖点，已废弃，勿录）。

## 录制前准备

1. 本地起 app（`streamlit run app.py`）或打开线上工作台；若线上休眠，先唤醒等 30 秒。
2. 浏览器只留必要标签页，**关掉微信/邮件/通知弹窗**；不展示 API Key、终端、个人账号或本地路径。
3. 需要出镜的画面文件提前打开：
   - `docs/evidence/security_benchmark.md`（69 条用例表）
   - `docs/charts/bigquant_preregister_raw.jpg`（0/5 原始截图）
   - `docs/bigquant_validation.md` §6 表格（Alpha#25 复现）
4. 演示模式先载入一个预置示例跑一遍，让体检结果有缓存，现场秒开。
5. 数字读法提示：【】内为口播注音，字幕必须与方案书一致。

## 0:00–0:20 开场：问题与立场

画面：工作台首页。

> "大模型几秒钟就能写出一个因子，但金融研究最危险的问题不是生成慢，而是把偶然收益包装成规律。因子实验室要解决的不是"让 AI 多生成"，而是"谁来限制、验证并否决 AI"。"

## 0:20–0:55 结构式安全

画面：AI 因子工场输入想法 → 生成 → 表达式树；切 security_benchmark.md。

> "Agent 不写 Python，只能在 **38 个白名单金融算子**里组合表达式。解析器逐节点检查算子、参数、隐藏字段、深度和节点数，求值器里没有 eval、没有 exec——结构安全，不是事后审查。我们用 **69 条固定用例**攻击它，危险输入拦截率百分之百；测试还真实发现过 signed_power 参数约束只写在文档、没有执行，修复后才是 69 全过。AI 有创造空间，但没有越权空间。"

屏幕强调：`38 operators`、`69/69`、`No eval / exec`。

## 0:55–1:25 体检与反思闭环

画面：体检报告滚动（IC、分层、换手、衰减）→ 经典因子库。

> "候选通过安全门后，自动完成每日截面 IC、五层分层回测、换手率、IC 衰减，还有 Newey-West 稳健 t 和多重检验校正。评分低于 50，体检诊断回喂给 Agent，最多反思两轮，每轮公式、评分、停止原因全部留痕——它接受失败，不无限重试。91 个经典因子和 AI 因子走同一条管线，我们没有为 AI 单独放宽标准。"

## 1:25–2:00 失败证据：0/5

画面：app 生成结果区的红色「独立复核：淘汰」横幅 → 原始截图 bigquant_preregister_raw.jpg。

> "接下来是最重要的一段。本地样本内，放量延续曾显示正收益——普通 Demo 到这里就结束了。我们把五个预注册候选送进 BigQuant 独立沙箱，动态沪深300、发现期与留出期双阶段复核：**0 个过关**。放量延续独立策略年化负 2.45%，系统将它淘汰。0/5 不是产品失败，是风控能力的证据：工作台能拦下一个看起来漂亮、但跨环境不稳健的候选。"

## 2:00–2:30 存活证据：唯一幸存者经得起复算

画面：bigquant_validation.md §6 表格（本地 vs BigQuant 对照）。

> "但故事还有另一半。91 个内置因子做完多重检验校正，名义显著的 7 个里只有 **1 个**活下来——Alpha#25。它在本地 HAC 稳健 t 值是 4.29，我们把它送进 BigQuant 独立数据环境用完全独立的实现复算：t 值 4.00，显著性复现。淘汰的证据公开，存活的证据也公开——我们不挑好看的结果展示。"

## 2:30–3:00 收束：落地与立场

画面：双股票池 / 策略对比 / GitHub README。

> "项目支持沪深300 与全 A 5300 只股票双池，行业市值中性化、扣成本策略回测，代码全部开源可复现。因子实验室的核心贡献，是把 AI 的创造力放进金融研究纪律：AI 负责提出候选，结构负责拦截，证据负责判定，人负责最终决策。"

## 录制验收

- 总时长 2:45–3:15。
- 首屏 10 秒内出现项目名与核心问题。
- 必须出现三个证据数字：`38`、`69`、`0/5`。
- 强烈建议保留 2:00–2:30 的 Alpha#25 段（91 挖 1 + 独立复现 t 4.00）——这是区别于"只会淘汰"的完整叙事。
- 不把本地 +14.4% 或任何样本内收益当作有效性结论说出。
- 不展示 API Key、终端、个人账号、本地路径；关掉通知弹窗。
- 字幕与口播一致（数字口径同方案书），1080p、16:9 导出。

## 录制方法（分段录，别一次到底）

1. 按上述 6 段**分段录屏**（每段 20–40 秒，NG 只重录本段），口播可在录屏后单独补录对齐。
2. 工具：Win+Alt+R（Xbox Game Bar，够用）或 OBS 1080p 30fps；画面 16:9。
3. 剪映拼接：画面操作与口播对齐，关键数字处加字幕。
4. 录完先自查验收清单，再交 Claude 复核（对时间轴、字幕与数字一致性）。
