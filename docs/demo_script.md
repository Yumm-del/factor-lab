# 3 分钟演示视频脚本

> 目标：让评委记住一句话——**我们不把 AI 当收益预言机，而是让它在受限、可验证、可否决的流程里做研究。**

## 录制前准备

1. 提前打开线上工作台；若出现休眠页，点击唤醒并等待约 30 秒。
2. 打开「AI 因子工场」中的离线预置示例，避免现场依赖 DeepSeek。
3. 准备三个画面：工作台首屏、安全基准报告、BigQuant 独立复核失败表。
4. 不现场承诺收益，不把本地样本内 +14.4% 当作有效性结论。

## 0:00–0:25 问题与立场

画面：工作台首屏。

> “大模型可以在几秒内写出一个因子，但金融研究最危险的问题不是生成慢，而是把偶然收益包装成规律。因子实验室要解决的不是‘让 AI 多生成’，而是‘谁来限制、验证并否决 AI’。”

## 0:25–1:05 结构式安全

画面：输入自然语言想法，展示表达式树；切到 `security_benchmark.md`。

> “Agent 不输出 Python，只能在 38 个白名单金融算子里组合表达式。解析器逐节点检查算子、参数、隐藏字段、深度和节点数，求值器没有 eval 或 exec 路径。我们用 69 条固定用例攻击它，合法公式通过率和危险输入拦截率都是 100%。测试还发现 signed_power 的参数边界只写在文档、没有真正执行，我们修复后才得到 69/69。”

屏幕强调：`38 operators`、`69/69`、`No eval / exec`。

## 1:05–1:45 Agent 闭环

画面：Agent 流程图和迭代轨迹。

> “候选通过安全门后，自动完成 IC、分层收益、换手、衰减、时间分割和 FDR 校正。评分低于 50，体检诊断会回喂给 Agent，最多反思两轮。每轮公式、评分和停止原因全部留痕。它不是无限重试，而是在同一套停止规则下接受失败。”

画面：经典因子库。

> “91 个经典因子和 AI 因子走同一条管线，防止我们为了 AI 的结果单独降低标准。”

## 1:45–2:30 最重要的失败证据

画面：BigQuant 独立复核表，突出 0/5。

> “本地样本内，放量延续曾显示正收益。如果只做普通 Demo，故事到这里就结束了。但我们把五个预注册候选送进 BigQuant，用动态沪深300、发现期和留出期双阶段复核，最终 0 个过关。放量延续的独立策略年化是负 2.45%，系统将它淘汰。”

> “0/5 不是产品失败，而是风控能力的证据：工作台能够阻止一个看起来漂亮、但跨环境不稳健的候选进入接纳层。”

## 2:30–3:00 落地与收束

画面：双股票池、策略构建、用户测试任务。

> “项目支持沪深300和全 A 5320只股票，提供中性化、扣成本策略和完整复现脚本。下一步不是夸大收入，而是用统一任务测试真实用户，再以持续使用和早期试用验证商业价值。”

> “因子实验室的核心贡献，是把 AI 的创造力放进金融研究纪律里：AI 负责提出候选，结构负责拦截，证据负责判定，人负责最终决策。”

## 录制验收

- 总时长控制在 2:45–3:15。
- 首屏 10 秒内出现项目名和核心问题。
- 必须出现 `38`、`69/69`、`0/5` 三个证据数字。
- 必须明确说出本地 +14.4% 未通过独立复核，不能作为接纳结论。
- 不展示 API Key、终端环境变量、个人账号或本地路径。
- 字幕与口播一致，1080p 导出，16:9。
