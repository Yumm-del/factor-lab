# 总决赛答辩 QA

> 回答原则：先给结论，再给证据，最后承认边界。任何未完成的实验都不得使用“已经证明”。

## Q1：你这算真正的 Agent，还是把 LLM 接到回测脚本？

**答**：它是一个有明确状态、行动边界、反馈与停止条件的单智能体。感知输入包括用户假设和体检诊断；行动只能是生成受限表达式；评分低于50时读取 IC、换手、单调性和衰减反馈并修改；最多两轮后停止。每轮轨迹可审计。当前不是多智能体，也没有跨会话长期记忆，这是明确边界。固定五题消融用于比较同一首轮起点下 single-shot 与完整闭环。

## Q2：LLM 被提示注入或输出恶意 JSON 怎么办？

**答**：安全不依赖提示词。`dsdl.parse_factor()` 在解析层逐节点检查算子白名单、参数范围、允许字段、深度和节点数；求值器没有任意代码执行路径。69条离线固定用例覆盖注入、越权算子、隐藏字段、NaN/Infinity、非法参数、畸形JSON和资源上限，当前69/69通过。基准还发现并修复过一个真实的参数约束漂移，因此不是展示性测试。

## Q3：为什么独立复核 0/5，还说项目有价值？

**答**：项目交付的是因子研究基础设施，不是一条承诺盈利的策略。0/5说明预注册候选没有经受住发现期、留出期和扣成本策略门槛；系统保存失败证据并拒绝接纳，正是价值所在。如果工具只展示本地最好看的曲线，它无法承担金融研究的风控责任。

## Q4：会不会因为大量挖因子产生多重检验和过拟合？

**答**：系统不是无约束枚举，用户先提出金融假设；同时提供 Benjamini–Hochberg FDR 校正、四折 walk-forward、生命周期图、双股票池和独立环境复核。91个内置因子中名义显著6个、FDR后0个，系统如实保留这个不漂亮的结果。当前样本仍不足以证明任何新因子具备可交易性。

## Q5：市值中性化为什么使用成交额和换手率？

**答**：在成交均价近似成立时，`成交额 ÷ 换手率`可作为流通市值代理，但它不是严格无误差恒等式，会受成交均价、换手率精度和停牌影响。因此方案书明确标注“代理变量”，接口可以替换为真实流通市值；机构落地时必须接入正式数据源并重新审计。

## Q6：与 Qlib、RD-Agent、BigQuant 或米筐有什么区别？

**答**：本项目不宣称单项方法首创。差异化是组合：面向 A 股个人研究者，以无 eval/exec 的受限 DSL 为行动边界，把经典对照、反思、双池、FDR、时间稳健性和跨环境淘汰放进同一开源工作台。Qlib/RD-Agent更偏研发框架；商业平台的数据和工程能力更完整。我们的取舍是牺牲任意代码自由度，换取结构安全与可审计性。

## Q7：现在能直接用于实盘吗？

**答**：不能。当前定位是研究工作台。固定20bps成本不能替代滑点、冲击成本、容量、涨跌停、停牌和真实成交建模；样本外跟踪时间也不够长。进入实盘前必须使用正式行情、交易约束、风险预算和合规审批。

## Q8：落地价值的证据是什么？

**答**：已经完成可访问工作台、双池数据、统一诊断、安全基准、复现脚本和独立失败复核；真实用户可用性测试正在按固定五步任务执行，最低有效样本5人，失败不剔除。在用户结果完成前，只能说“产品已可用”，不能说“用户价值已验证”。

## Q9：商业模式为什么可信？

**答**：竞品年费只能证明量化工具存在付费品类，不能证明本项目有人买。项目采用分阶段门槛：先取得不少于30名持续使用者，再完成10名增值功能访谈，至少3人愿意参加可退款早期试用后才测试收费；未达标就继续验证问题，不预设收入。
