# 答辩 QA 准备（评委高频问题 → 答案要点）

> 用途：总决赛答辩/演示视频 Q&A 环节。答案全部基于项目真实实现，不背书不夸口。
> 若被追问而答案里有"尚未实现"，直接承认并给出后续计划——诚实是被接受过的（本项目的主线叙事）。

## Q1：如果 LLM 绕过 JSON Schema，构造很深嵌套的恶意表达式，你的防护怎么做？深度 8、节点 64 上限为什么选这两个数值？

**要点**：
- **防护在解析层，不依赖 LLM 输出校验**：LLM 输出先过 JSON Schema 校验，但真正的拦截发生在 `dsdl.parse_factor()`——解析器递归解析表达式树时逐节点检查（算子是否在白名单、param 是否在允许区间、深度/节点是否超限），**非法输入在解析层直接被拒绝并给出中文错误**。LLM 输出校验只是第一道滤网，解析器才是结构保证。
- **深度 8 / 节点 64 的来源**：对 A 股因子常见表达式的复杂度统计——经典因子（低波动、动量、量比等）深度 3~5、节点 5~12；深度 8 / 节点 64 是"覆盖全部有意义表达式 + 留出探索余量"的上限。更深的树在金融上几乎无意义（信号衰减），反而制造过拟合空间。
- 可补充：`param` 窗口也有边界（1~260），时序算子窗口不能为负/零。

## Q2：AI 自动搜索因子，会不会在历史数据上过度挖掘？多重检验问题怎么处理？

**要点**：
- **本项目不是大规模暴力遍历**：不是让机器枚举上万个因子再挑最好看的——而是**人给自然语言想法，AI 翻译成表达式，人主导假设**。假设空间由人划定（"放量后延续上涨"），AI 只是把想法变成可验证的表达式，多重检验的膨胀远小于机器暴力挖掘。
- **三层防线**：评分 tanh 压缩（极端值封顶，防止过拟合因子刷分）→ 生命周期监控（60 日滚动 IC，失效如实画出）→ 经典因子对照组（验证管线本身正确）。
- **已做 FDR 多重检验校正（2026-08 新增）**：Benjamini-Hochberg 程序对因子池批量校正。真实数字不粉饰——**91 个内置因子（沪深300 全样本）名义显著（|t|≥2）6 个，校正后 0 个**（最佳 Alpha#25：t=3.27，q=0.0975 未过 0.05）。这个「不好看」的结果恰恰说明系统不会因挖得多就宣称有效；校正后的 q 值将作为因子合成层的入池门槛。
- **已做 walk-forward 时间分割（2026-08 新增）**：样本按时间均分 4 折逐折独立评估，检验能力是否时间平稳。实测：动量20 四折同号（+0.0011 ~ +0.0096）判定平稳但强度弱；低波动20 前两折 +0.021、后两折 −0.026 → 漂移风险（与生命周期图 2025-26 风格切换互相印证）；Alpha#12 方向反复翻转 → 漂移风险。结论：全样本数字须连同分段稳健性一起解读，实盘按最新一段重估。
- **样本外跟踪（2026-12 阶段三）**：提供真正的样本外证据（每日生成信号、不实际下单，已自 2026-08-17 提前启动）。

## Q3：中性化里用「成交额/换手率」替代流通市值，误差怎么控制？

**要点**：
- 数学关系：流通市值 = 成交额 ÷ 换手率（换手率 = 成交量 ÷ 流通股本，按金额口径成交额 ÷ 换手率 = 市值），这是**恒等式而非经验近似**。
- 实际误差只来自数据口径：换手率四舍五入到 0.01%、停牌日异常值——量级可忽略的噪声。
- 取舍：为了不引入额外数据源（保持免费数据闭环）；接口已抽象为函数，后续可直接替换真实流通市值字段。

## Q4：回测很好，真拿这个工具做实盘，最大短板是什么？

**要点**（先承认短板，再给防线）：
- **滑点与冲击成本**：当前回测只扣双边 20bps 固定成本，未建模冲击成本与资金容量——大资金进出会显著劣化表现（尤其小市值票）；
- **风格切换**：生命周期图已证明因子会失效（低波动 2025-26 反转）——实盘必须动态监控与调仓规则配合；
- **边界**：工具是研究工作台，输出是"候选因子 + 验证证据"，**不直接产生交易信号**；2026-12 阶段三的样本外动态跟踪会实证滑点模型。

## Q5：对比 RD-Agent / Qlib，你的核心取舍是什么？

**要点**：
- RD-Agent/Qlib 走「LLM 写 Python 代码 + 回测防火墙」——安全靠**约定**（事后审查/沙箱），且面向机构数据环境；
- 本项目走「LLM 输出受限 DSL 表达式树」——安全靠**结构**（解析层白名单拦截），付出的是表达自由度：不能写任意 Python 逻辑；
- 换回什么：结构性安全、全流程可解释（表达式树可读可改）、本地开箱即用、免费数据源闭环、面向 A 股个人研究者——这是把"AI 量化"从机构工具下沉为个人工作台的取舍。

## Q6（可能的追问）：AI 生成失败的情况怎么办？

**要点**：
- 过滤漏斗：生成 → DSL 校验（解析层拦截非法）→ 体检（评分 <50 淘汰/触发反思迭代）→ 达标才进策略层；
- 反思迭代实测保留每轮轨迹，包括评分回落的轮次——不粉饰失败；
- 演示兜底：预置示例（presets.json）离线可演示。
