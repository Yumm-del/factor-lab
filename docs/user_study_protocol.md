# Factor Lab 真实用户测试方案

## 目的

验证产品是否真的帮助量化初学者完成“理解因子—查看体检—作出保留或淘汰判断”，而不是只验证作者本人会使用。该测试不评价参与者的投资能力，不收集账户、持仓或真实交易信息。

## 样本与边界

- 目标人数：8 人；最低有效样本：5 人。
- 初学者至少 5 人：未独立完成过因子 IC 与分层回测。
- 有经验者最多 3 人：学过 Python、统计或量化课程。
- 参与完全自愿；只记录匿名编号、经验等级和任务指标。
- 不能伪造、补写或美化结果；未完成同样属于有效证据。

## 固定任务

所有参与者使用同一版本、同一预置数据和同一任务说明。测试者只能朗读任务，不解释按钮位置或指标答案；确需帮助时记录一次 `help_count`。

1. 打开工作台并加载“低波动率”预置示例。
2. 找到系统给出的体检结论、RankIC、换手率和风险提示。
3. 回答：该因子能否直接视为稳定可交易因子？为什么？
4. 打开“放量延续”案例，判断系统最终是保留还是淘汰该候选。
5. 找到支持该判断的独立复核或生命周期证据。

## 成功标准

- `completed=1`：参与者在 15 分钟内完成全部五步。
- `decision_correct=1`：明确回答“不能直接视为稳定可交易因子”，并能指出留出期、交易成本、独立复核或状态依赖中的至少一项。
- `false_positive_avoided=1`：没有因为看到本地正收益而错误保留“放量延续”。
- `help_count`：测试者提供提示的次数。
- `ease_score`：参与者对易用性的 1–5 分评价。
- `trust_score`：参与者对“能理解系统为何拒绝因子”的 1–5 分评价。

## 操作流程

1. 复制 `docs/evidence/user_study_template.csv` 为 `docs/evidence/user_study.csv`。
2. 每完成一名参与者，立即增加一行；不要事后凭记忆批量填写。
3. 原始 CSV 只使用匿名编号，不写姓名、手机号或学号。
4. 运行 `python scripts/summarize_user_study.py`。
5. 当有效样本少于 5 人时，报告会明确标记“证据不足”，不得写入项目书作为已验证结论。

## 项目书可采用的结果口径

只有脚本生成的指标可以进入项目书：有效样本量、完成率、正确判断率、避免假阳性比例、完成时长中位数、平均求助次数、易用性与可信度均值。用户原话只能匿名引用，不得把单个好评写成整体结论。
