# 真实用户测试招募与主持稿

## 可直接转发给参与者

你好，我正在测试一个参加“北京大学金融 AI 智能体创新大赛”的量化研究工具，想邀请你做一次 **10–15 分钟匿名可用性测试**。

- 不要求会量化或编程，初学者正是目标用户；
- 不收集姓名、学号、手机号、账户、持仓或交易信息；
- 不是投资测试，也不要求你相信或购买任何因子；
- 只观察你能否找到系统结论，并判断一个因子是否应该被淘汰；
- 测试中遇到困难也很有价值，请不要担心“做错”。

测试地址：<https://factor-lab-29n3ulxfgehjfbj5phsapi.streamlit.app/>

首次打开如显示休眠，请点击 “Yes, get this app back up!” 并等待约30秒。测试需要一位主持人在线或在旁记录；请回复一个方便的15分钟时间段。

## 主持人开场白

> 这不是考试，我测试的是产品，不是你。请尽量自己寻找，不需要猜我想听什么。你可以把正在想的事情说出来；如果需要我提示，请直接说，我会记录一次求助。整个过程不录入姓名、账号或投资信息。

## 固定任务卡

主持人只朗读任务，不解释按钮位置或正确答案。

1. 打开「AI因子工场」中的「演示模式」，载入“低波动率”示例。
2. 找到本地体检结论、RankIC、换手率和跨环境接纳结论。
3. 回答：这个因子能否直接视为稳定可交易因子？为什么？
4. 载入“放量后价格延续上涨”示例，判断最终状态是保留还是淘汰。
5. 找到支持该决定的独立复核数字或风险证据。

## 结束提问

1. 易用性打几分？1=很难使用，5=非常容易。
2. 你能否理解系统为什么拒绝一个本地收益为正的因子？可信度打几分？1=完全不能，5=完全能。
3. 哪一步最困惑？
4. 如果下周还要判断一个新因子，你愿不愿意再用这个工具？为什么？

## 主持人记录规则

- 开始第一步时计时，完成第五步或15分钟到时停止。
- 参与者每次明确请求方向性帮助，`help_count` 加1；只重复任务原文不计。
- 没做完也记录，`completed=0`，不得删除失败样本。
- `decision_correct=1`：回答“不能直接视为稳定可交易”，并指出留出期、独立复核、交易成本或状态依赖至少一项。
- `false_positive_avoided=1`：没有因为本地正收益而保留“放量延续”。
- 记录到 `docs/evidence/user_study.csv`，只使用匿名编号 `P01`、`P02`……
- 评论栏只写与产品相关的原话，不记录身份信息。
